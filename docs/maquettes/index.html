Parcours client par QR code

Le client scanne le QR code de la table T7 avec l'appareil photo de son téléphone. Le menu s'ouvre dans le navigateur, sans installation.

  1. Le client choisit ses articles et envoie sa commande.
  2. La commande arrive chez le serveur (onglet Serveur, table T7 en violet), qui la valide ou la refuse.
  3. Une fois validée, les bons partent en cuisine, grill ou bar.
  4. Le client suit l'avancement sur son téléphone et peut demander l'addition.
  5. Le paiement se fait à la caisse.

Sécurité : le QR code contient seulement un identifiant de table aléatoire. Il ne donne accès ni aux fonctions internes, ni aux autres tables, ni aux rapports. Un QR code désactivé ne permet plus de commander.
